# PCN Cloud — Marketing site (`www.pcncloud.in`)

Premium B2B landing for hospitality IT, built with **Next.js**, **Tailwind CSS**, and **Framer Motion**.

## Local

```bash
cd go-site
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Vercel

Create a **separate** Vercel project (not the admin panel):

| Setting | Value |
|---------|--------|
| Root Directory | `go-site` |
| Framework | Next.js (auto) |
| Domains | `www.pcncloud.in` + apex `pcncloud.in` → www |

Admin stays on **`admin.pcncloud.in`** (Root Directory `admin-panel`).

Client Login CTA → `https://admin.pcncloud.in`.
